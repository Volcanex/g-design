Shipping the edition

Rendered markdown gets the .prose class and nothing else. Width caps at 68 characters, the line height opens up to 1.65, and headings keep the interface scale so documents and dashboards feel like one product.

How publishing works

An edition is a frozen static build. The pipeline compiles every post, stamps the grid, and swaps the symlink; nothing is rendered at request time. Rolling back is pointing the symlink at the previous edition.

Publish is the same word the whole way through: the Publish button makes a Published toast and a published edition.
  • Posts are files under pages/, one directory per post
  • Drafts never leave the machine they were written on
  • Images are downscaled at compile time, not upload time
