Everything lands on 4px

One base step, and a spacing scale built from it: 4, 8, 12, 16, 24, 32, 48, 64. Nothing between them. A page that keeps to it stays aligned as it grows, and two authors working on neighbouring panels reach the same number without a conversation.

A control, --h-3, 32
A text row, --lh-2, 20
A table row, --h-4, 40

Vertical rhythm

Line-heights are pixels, not ratios. The ratio 1.5 puts a 13px row on 19.5px and a 15px row on 22.5px, and after that nothing beneath them can sit on the grid. Half-pixel edges also make Safari draw a hairline border at double weight.

Height scale

Controls and rows take a height from one scale, so neighbours share a bottom edge without anyone measuring. Density remaps which step a control lands on, never the scale itself.

The reserved slot

A slot that is empty most of the time keeps its size. An error line, a count, a status badge, a spinner: give the slot its height before anything arrives, so its neighbours never move when it does.

Waiting

The test is a layout-shift observer, not an opinion. Watch the page while the data lands, and nothing that was already on screen may move.

Audit it

The audit renders a page and reports every edge off the grid, every half-pixel edge and every sibling gap off the scale, grouped by selector.
