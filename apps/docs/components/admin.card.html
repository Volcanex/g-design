Arm a browser once with ?gadmin=1, or press cmd shift K, and every page that ships g-ui.js grows this bar, for that browser and that admin session only. The same keys take it away again. Where the host page rebranded g-design, the overlay wears that accent too. Annotate mode pins elements and draws over them. Edit mode selects one and edits its spacing, alignment and type live, snapped to the spacing scale the host page declares. Nothing writes to source: both save a ticket, and an agent bakes it afterwards.

X-ray is a lens over either mode: it paints every visible box at once, margin in one tint and padding in another, outlines fading with nesting depth, and flags any edge off the 4px grid. In edit mode [ and ] walk the selection up and down the ancestry, alt-click reaches an element another element covers, and the breadcrumb under the selector says where you are. Esc steps back out one layer at a time.

Every applied edit flashes the box it changed, and the margin pane says so when a margin will not behave: an inline box, a positioned element, an item spaced by its flex or grid container. Edits are written inline and mirrored into one stylesheet in the head, so they survive an app page that rebuilds the element underneath them. Revert takes both away.

With something selected, hovering anything else measures the distance between the two and names the spacing stop each gap is nearest, in the warning tint where it is on none. shift click adds to the selection and the controls then write to every element in it. delete hides one, as a pending display: none that reverts and tickets like any other edit. The text tool, t or the switch in the bar, edits a line of copy in place and saves it as a content ticket. shift / lists every key.

A multi-selection says what its elements have in common, the shared tag and every class all of them carry, or the tags it is mixed from. Where they share a tag and a class it offers to select everything else like it on the page, up to the eight a ticket carries, and says so when that cap bites. The shape goes into the ticket summary too, so a baking agent reads six edits on three elements as one change to a class rather than three coincidences.

Every measured gap is clickable. The chip jumps the selection to whatever owns that gap, the container's padding, the container's own gap, or a sibling's margin, opens the pane the property lives in and flashes the row, and says in one line what it decided. Where two declarations are both adding to the gap it names the one it did not pick.
