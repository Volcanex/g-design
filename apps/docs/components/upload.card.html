The pinned bar One bar owns the whole job and sticks to the top edge of the panel, so it stays in view however far you scroll the list. It squares off flush with the edge: pinned progress is an edge, not an object.
Per asset Each row carries its own bar, rate and status, because one stalled file among six is the thing you need to see. A bar says how far; the readout beside it says how fast and how much longer, in mono tabular figures so the numbers never shift the row.
Leaving the panel Close the panel mid-upload and the work keeps going in a loading toast, which resolves in place. Progress never lives only inside the thing that started it.
